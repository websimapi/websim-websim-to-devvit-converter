WebSim → Devvit

Convert WebSim projects into ready-to-launch Reddit Apps

Devvit Structure

  • Uses standard Webview mode
  • Pre-configured Express server
  • Assets placed in web/ folder
  • Ready for Redis and Realtime APIs

How to run

  1. Extract the ZIP file
  2. Run npm install
  3. Run devvit login
  4. Run npm run dev
